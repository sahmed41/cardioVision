# CardioVision

## Project Overview & Key Features 
Detailing the workflows for patients (including your secure DocCode mechanism to prevent self-diagnosis) and primary physicians.

## Architecture & Technology Stack
Highlighting your decoupled design (HTML5/CSS3/jQuery frontend, PHP backend, MySQL relational database with four core tables, and FastAPI ML server).

## Deep Learning Details
Specifying the VGG-16 Convolutional Neural Network (CNN) parameters and its binary classification training metrics using the Mendeley dataset.

## Local Setup Instructions
Step-by-step setup guides for both the XAMPP (Apache/MySQL) local server and the Python virtual environment for FastAPI.

## Testing & Security Objectives
Documenting functional validation, user acceptance testing (UAT), and the five core pillars of system security (Confidentiality, Integrity, Availability, Authorization, and Non-repudiation).
